# 项目结构

| 位置 | 用途 |
| --- | --- |
| `一键启动.bat`、`Start-MindGarden.ps1` | Windows 启动入口与环境检查 |
| `MindGarden/app.py`、`themes.py` | 应用入口、模板上下文、主题存储与素材解析 |
| `MindGarden/routes/`、`services/`、`user_profile/` | 页面和 API、创作与陪伴服务、用户画像 |
| `MindGarden/models/` | 数据库访问代码和本地模型加载入口。部署所需依赖见安装文档 |
| `MindGarden/templates/`、`static/css/`、`static/js/` | 页面、样式与交互；通用引导从 base.html 接入 |
| `MindGarden/static/garden/lobby/`、`static/candy/` | 风格大厅插画与小屋通用素材 |
| `MindGarden/static/garden/illustrated/` | 三个时段的二维全景、原画图层、四处近景和室内图 |
| `static/js/illustrated_garden.js`、`static/js/garden_life.js` | 景点切换、敲门、抽笺、翻画、移动日月，以及贴合画稿的时钟和水纹 |
| `static/css/illustrated_garden.css`、`static/css/illustrated_objects.css` | 桌面与竖屏的构图、层叠顺序、金光和物件位置 |
| `static/js/garden_passage.js`、`static/css/garden_passage.css` | 从大厅选定时段的日月过渡到对应原画 |
| `MindGarden/templates/_garden_return.html`、`static/css/destination_return.css` | 景点共用的返回纸签 |
| `static/garden/hosts/` | 糖糖、清禾和星芽的门前与室内立绘 |
| `static/js/paper_stage.js`、`anime_quarter.js`、`season_world.js`、`static/garden/paper-covers/` | 前一版三维花园的源码与实拍留档 |
| `MindGarden/data/`、`crewai_storage/`、`genres/` | 使用过程中在本机保存的陪伴记录、剧本状态和生成作品 |
| `工具/` | 初始部署、环境验收、AI 诊断、五色场景素材导出 |
| `MindGarden/mysql teaching.sql` | 首次部署的空库结构 |
| `MindGarden/static/music/` | 自备授权配乐的放置目录 |
| `文档/素材来源/` | 第三方资源原始说明及本次新增美术说明 |

## 从页面定位源码

| 页面 | 地址 | 模板 |
| --- | --- | --- |
| 风格大厅 | `/` | `index.html` |
| 三时段花园与喷泉池畔 | `/garden` | `creation/garden.html` |
| 樱桃小屋 | `/candy-house` | `chat/candy_house.html` |
| 喷泉舞厅 | `/garden/mirror` | `creation/mirror.html` |
| 艺术回廊、创作 | `/gallery`、`/create` | `creation/gallery.html`、`creation/create.html` |
| 树洞书桌、历史记录 | `/journal/create`、`/journal` | `journal/create.html`、`journal/index.html` |

网页直接使用 `MindGarden/static/garden/illustrated/` 下的成图。可学习的画稿和分层位于 `MindGarden/static/garden/themes/`。替换素材时可按时段组织自己的 WebP，过程见[二维花园素材说明](素材来源/二维花园.md)。

数据库、用户作品、会话记录和密钥与美术素材分开管理。恢复历史数据前先留存当前数据库与对应文件。
