# 樱桃小屋插画来源

## 三时段迎客角色

三幅透明全身立绘在三维版改造时由 ImageGen 绘制，二维花园沿用了这三位主人。屋前和室内使用同一位角色。下表中的茶室、花房是早期室内设计；当前各时段的小屋外观和室内取自二维工作稿。[三位主人立绘](../../MindGarden/static/garden/hosts/) · [当前小屋画面](../../MindGarden/static/garden/illustrated/)

| 素材 | 绘制要求 |
| --- | --- |
| 糖糖 | 朝来客微笑的花店店长，栗色短发、抹茶围裙、黄色小花束 |
| 清禾 | 清雅稳重的年轻茶室主人，素青汉服、盘发、收拢的折扇 |
| 星芽 | 俏皮的夜园女孩，深蓝发辫、星纹裙摆、抬手提一盏花灯 |
| 听水茶室 | 午间侧光照进木格窗，低案上有两只青瓷茶盏，开窗可望远山与亭榭 |
| 星灯花房 | 冷月下的花房，暖灯照亮木案与花盆，石拱外有绣球与上行花径 |
| 大厅与夜园月面 | 暖白、蓝灰矿物肌理，略有缺相的写实手绘月轮 |

## 早期小屋素材

早期版本使用内置 ImageGen 生成外观、三套室内底图和可爱风女巫的四姿势图。清新风和丑萌风沿用既有人物造型，以小屋五色重新导出。各图后的排版、文字和交互均由页面渲染。

| 资产 | 生成画面要求摘要 |
| --- | --- |
| 外观 | 透明底，三分之四视角。奶油色木结构、樱桃红斜屋顶、拱形绿门、金色窗户及屋顶双樱桃标志 |
| 可爱风室内 | 横幅木刻茶室。拱窗、樱桃树枝、茶壶和草药架，墙面留白，细排线 |
| 清新风室内 | 植物工作室。开花的樱枝、绿丘、小瓶和植物笔记，鼠尾草绿与留白为主 |
| 丑萌风室内 | 歪斜的茶室。圆窗、小柜、摇摇晃晃的茶壶，大块奶油色与蜜黄 |
| 可爱风女巫 | 同一位女巫，透明底四联图。依次为端杯、递樱桃、托腮和挥手。以五种印色表现帽子、短发和长裙 |
