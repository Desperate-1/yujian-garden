# 二维花园原稿

## 使用与替换插画

花园页面直接读取 `MindGarden/static/garden/illustrated/` 下的 WebP 成图。每个时段各有一个目录，清晨为 `cute`，正午为 `fresh`，入夜为 `ugly`。已经有成图时，按根目录 README 的步骤启动即可。

如果希望使用自己的图，可以直接按下面的约定导出到对应时段的目录。向他人发布项目时，选用自己有权分发的素材，并为插画单列来源和许可。

| 用途 | 每个时段所需文件 | 绘制约定 |
| --- | --- | --- |
| 花园全景 | `sky.webp`、`orb.webp`、`gallery.webp`、`journal.webp`、`ground.webp`、`candy.webp`、`fountain.webp` | 各层共用 1920 × 1080 的画布和坐标。按表中顺序叠放，天空以外的图层保留透明区域；可拖动的日月绘在 `orb.webp`。 |
| 大厅转场、静态底图 | `entrance.webp` | 使用同样的画布，把上面七层合成一张完整画面。 |
| 四处近景 | `candy-detail.webp`、`journal-detail.webp`、`gallery-detail.webp`、`fountain-detail.webp` | 使用 3∶2 横幅插画。各张图分别画屋门、树洞、回廊、池畔。 |
| 玩法页面 | `room.webp`、`desk.webp`、`wall.webp`、`hall.webp` | 分别是小屋室内、日记书桌、展墙和舞厅。 |

如果新构图移动了房门、树洞或水池，需同步调整 `static/css/illustrated_garden.css` 的全景热区和 `static/css/illustrated_objects.css` 的近景、日月位置。钟面、喷泉和表情的位置见 `static/js/garden_life.js` 的分时段画稿坐标。资源确认后，分别在桌面和竖屏点击这四个地标检查对齐。

## 原版素材溯源

清晨、正午和入夜使用本项目三维改版前的二维插画。以旧版实拍 `p17_garden_实拍.png` 核对小屋、树洞、回廊、喷泉和石径的相对位置。天空、回廊、树、草地、小屋和喷泉沿用同一张 3584 × 2016 画布的坐标，网页按 1920 × 1080 导出。房门、书笺和画框的点击区域随整张画一起缩放。

| 画面 | 原稿与处理 |
| --- | --- |
| 清晨 | 使用旧工作稿「cute对齐前备份」里的糖霜小屋，以原对齐方式放回樱花树左下方。屋前近景取自这张复原的全景，室内取自旧包的 `static/candy/room.png`。 |
| 正午 | 使用 `static/garden/themes/fresh/` 的淡彩石径、树荫和池水。绿藤小屋、入口近景和室内取自旧上传快照。 |
| 入夜 | 使用 `static/garden/themes/ugly/` 和旧上传快照的紫色糖霜屋、圆窗和池畔。原稿调为冷色月夜，天空使用大厅的月亮并补入星光。 |
| 三套场景 | 两个日间场景的太阳从原天空单独分层，拖动后仍能看到连续的天空。时钟、喷泉、树洞书桌、舞厅和展墙沿用对应时段的绘画。三位主人的立绘来自项目现有的 `static/garden/hosts/`。 |

场景工作图位于 [主题画稿目录](../../MindGarden/static/garden/themes/)，复原后的房屋与室内成图见[运行用插画](../../MindGarden/static/garden/illustrated/)。部分旧画左下角自带「AI生成」标记，复原画面保留原标记。[三个时段的入口实拍](../界面预览/二维花园/三时段入口.webp)

制作记录中的重建工具可供阅读分层合成、调色和近景裁切的实现。持有原始素材包的维护者可用 `--archive` 指定本地档案，重建会覆写三个时段成图。自行创作时可以直接使用自己导出的 WebP。[二维导图脚本](../../工具/导出二维花园.py)
