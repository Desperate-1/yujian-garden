# 第一次进花园

1. 第一次运行请先按[安装部署](02_安装部署.md)准备环境。双击项目根目录的 `一键启动.bat`。保留启动窗口，在浏览器里打开的风格大厅继续。
2. 在天空下的三个椭圆里选一个。清晨去晨日樱花园，正午去云汀水院，入夜去月下花园。点击、轻触，或用 Tab 键聚焦后按回车，日月便会沿弧线移向选中的时段。试着用鼠标扫过下方的草梢，经过的草丛会摇晃回弹。
3. 点三个椭圆下方的「开始游园」。首次使用会进入注册页，已有账号可以点「已有账号？登录」，已登录时可直接进花园。
4. 点插画里的金光即可走近景点。到小屋先敲门，再点迎客的女孩进入聊天。到树洞先抽笺，再点展开的纸进入书桌。到回廊先翻画，再点画框进入展厅。用键盘时按 Tab 选择物件，按空格操作机关。近景下方和右上角「花园导航」也有直接进入玩法的链接。
5. 点画面右侧的喷泉或下方的「去喷泉」按钮到池边。用鼠标划过池水可看见水纹，点喷泉或「进入舞厅」就能去选舞伴。在全景还可以拖动太阳或月亮，或者按 Tab 选中它，再按方向键移动。
6. 首次访问时跟随指引卡片。点「下一步」看后续操作，点「跳过」开始自由使用。「操作指引」可重新打开。

从四个功能页离开时，点左上角「回到花园」回到该景点，再点一次回到当前花园的入口。「花园导航」里的「看近景」可以走到下一个景点。二维游园支持关闭 WebGL 的浏览器。

此前选过丑萌风的账号，回到大厅时会落在「入夜」。每个时段都有独立建筑、植物、天空和迎客角色。公开版默认安静游览。想给晨景配乐，可将自己有权使用的音频放到 `MindGarden/static/music/`。有曲目后，晨景音乐默认以 12% 音量淡入，播放器会记住手动调节的音量和暂停。正午和夜间舞厅可以跟随画面进行无配乐练习。[添加音乐](../MindGarden/static/music/README.md)

| 景点 | 第一次可以试试 |
| --- | --- |
| 树洞日记 | 写下一件今天发生的小事，点「写好啦，收进树洞」。从日记列表打开原文。 |
| 小屋、茶室或花房 | 把鼠标移近糖糖、清禾或星芽，停一停，或点她打个招呼。想聊天时，在输入框写一句话发给她。 |
| 心灵喷泉 | 在花园用鼠标划过池水，观察水纹。走进舞厅后可挑选舞伴，开启摄像头跟跳。 |
| 艺术回廊 | 点「开始一次创作」，拍照或从相册选择图片，选择创作类型；生成后回到回廊查看。 |

打开系统的「减弱动态效果」后，大厅的日月直接就位，花园的树冠和水面保持静止，时钟按分钟更新。入园转场也可按 Esc 跳过。喷泉摄像头和麦克风建议从电脑本机地址访问。退出账号可使用页面上的「退出」。
