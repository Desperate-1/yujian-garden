# 使用与排障

| 现象 | 处理 |
| --- | --- |
| 双击后启动失败 | 查看启动窗口最后的提示。启动器记录位于 `MindGarden/logs/launcher.log`，应用日志位于 `MindGarden/_app_out.log`。 |
| PORT 已被使用 | 在原来的启动窗口按 Ctrl+C，或在新的 PowerShell 窗口设置 `$env:PORT='5001'` 后启动。 |
| Python 不可用、缺少模块 | 用项目的 `.venv/Scripts/python.exe -V` 验证解释器；换机请按[安装部署](02_安装部署.md)重建环境。 |
| 能看见大厅，登录或保存却失败 | 按[安装部署](02_安装部署.md)核对本机的 MySQL 连接、服务账号权限和空库结构。 |
| 聊天或剧本功能异常 | 检查 MongoDB 的 27017 端口、云端服务凭据和网络。系统代理失效也会使云端请求超时。 |
| 摄像头或麦克风按钮不可用 | 从本机 localhost 或 127.0.0.1 访问，允许当前站点使用设备，关闭占用设备的软件。手机通过普通 HTTP 局域网地址访问时，浏览器可能限制设备权限。创作可从相册选图。 |
| 第一次进花园，怎样找到入口 | 点插画里的小屋、树洞、回廊或右侧喷泉。物件附近有金光，右上角「花园导航」也列出了四个玩法。 |
| 喷泉水束保持静止 | 检查系统的减弱动态设置。返回前台后，普通动效会继续播放。 |
| 走到喷泉边，怎样进舞厅 | 鼠标划过池水会带起涟漪。点画中的喷泉，或点下方「进入舞厅」。 |
| 从功能页怎样回到来时的位置 | 点左上角「回到花园」回到刚才所在的屋前、树洞、展板或池边。再点一次返回小径。「退出账号」用于结束登录。 |
| 清晨没有音乐入口 | 在 `MindGarden/static/music/` 放入自备的授权音频后刷新花园。初始仓库的歌单为空。[歌单说明](../MindGarden/static/music/README.md) |
| 想再看一次指引 | 进入相关页面，点「操作指引」。清理浏览器站点数据会重置已读进度。 |
| AI 生成失败 | 核对所选功能需要的密钥、接口额度、模型目录和网络。运行 `工具/AI链路诊断.py` 会实际请求所配置的云服务。 |

需要协助时，记录所处页面、刚执行的操作和错误类型。分享日志前去掉账号、私人内容及服务凭据。
