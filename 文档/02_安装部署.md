# 安装与启动

下面以 Windows、64 位 Python 3.10 和一套本机数据库为例。在仓库根目录打开 PowerShell。

## 1. 准备 Python 环境

```powershell
py -3.10 -m venv .\MindGarden\.venv
.\MindGarden\.venv\Scripts\python.exe -m pip install --upgrade pip
.\MindGarden\.venv\Scripts\python.exe -m pip install -r .\MindGarden\requirements.txt
```

## 2. 连接数据库

准备已启动的 MySQL 和 MongoDB。请在 MySQL 中为项目准备专用数据库和可在该库建表、读写的账号。如果数据库还没有建立，初始化脚本会尝试建库，此时所用账号须具备建库权限。首次部署建议选择空库。

在当前 PowerShell 中设置连接信息。将示例账号改成你的 MySQL 账号，输入密码时终端会隐藏字符。`MONGO_URI` 应包含数据库名，启用认证时使用自己的认证连接串。

```powershell
$env:MYSQL_HOST = '127.0.0.1'
$env:MYSQL_PORT = '3306'
$env:MYSQL_DATABASE = 'yujian_garden'
$env:MYSQL_USER = 'yujian'
$env:MYSQL_PASSWORD = [System.Net.NetworkCredential]::new('', (Read-Host 'MySQL 密码' -AsSecureString)).Password
$env:MONGO_URI = 'mongodb://127.0.0.1:27017/yujian_garden'
powershell -NoProfile -ExecutionPolicy Bypass -File .\工具\部署数据库.ps1
```

这个脚本使用仓库里的空表结构并验证 MongoDB 连接。数据库连接选项同时用于注册登录、日记和作品。首次运行会自动生成保存在 `MindGarden/instance/session.key` 的签名密钥；也可自行设置 `SECRET_KEY`。本地凭据与会话密钥留在各自电脑上。

如需由脚本启动 Windows 便携版，将官方安装包命名为 `mysql.zip` 和 `mongodb.zip`，放进当前用户目录的 `DBInstallers`。首次初始化本机便携 MySQL 时用 `root` 并设置自己的 `MYSQL_PASSWORD`。使用脚本管理的本机 MongoDB 时，留空 `MONGO_URI`，采用默认本机库。安装位置为当前用户目录下的 `DBPortable`。

## 3. 打开网站

```powershell
.\一键启动.bat
```

默认地址为 `http://127.0.0.1:5000`。在网页上注册新账号，选择时段后即可游园。按 Ctrl+C 停止网站。上述环境变量对当前 PowerShell 及它启动的程序有效。以后双击启动时，请先在 Windows 用户环境中配置相同的数据库连接信息，或在新的 PowerShell 中重复设置。调试时也可以进入 `MindGarden`，用 `.venv\Scripts\python.exe app.py` 运行 Flask 入口。

## 按需开启的功能

- 背景音乐读取 `MindGarden/static/music/` 中自行准备的授权曲目。
- 舞伴使用随包的浏览器端关键点模型。在本机地址打开舞厅并授予摄像头权限即可使用。
- 云端对话、语音和艺术生成通过 `工具/设置API密钥.ps1` 配置。启用语音转码需要把 ffmpeg 加入 PATH 或放在 `DBPortable/ffmpeg/bin/`。
- 需要剧本编排或本地生成后端时，在仓库根目录运行 `.\MindGarden\.venv\Scripts\python.exe -m pip install -r .\MindGarden\requirements-ai.txt`。本地生图、动画和音乐使用额外模型，合计约 13 GB，可按[模型目录说明](../MindGarden/models/请把模型放在这里.md)从相应发布方获取。

## 首次发布的验证范围

基础依赖在新的 Windows Python 3.10.11 虚拟环境从 PyPI 安装，`pip check` 通过。用临时空库验证了注册、三个时段的主题保存和原画加载，断网时也能用本地词典进行分词和日记评分。另用隔离的 MySQL 与 MongoDB 启动发布副本，通过真实 HTTP 请求检查了匿名登录保护、三个时段的游园以及四个玩法页面，并验证重复运行建表脚本会保留已有数据。

可选 AI 依赖已和开发环境中的软件包版本核对。本轮没有调用付费生成、下载大型权重或开启真实摄像头。
