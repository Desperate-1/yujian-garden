# 樱桃小屋美术素材

从花园点击「樱桃小屋」，先看到建筑近景，推门后进入 `/candy-house`。室内画面使用纸本色、墨紫、鼠尾草绿、樱桃红和蜜黄五种印色。插画导出为索引 PNG，人物额外保留透明通道。

| 印色 | 色值 |
| --- | --- |
| 纸本色 | `#F7EACF` |
| 墨紫 | `#322A38` |
| 鼠尾草绿 | `#7C9484` |
| 樱桃红 | `#A64753` |
| 蜜黄 | `#DEA959` |

## 素材位置

| 画面 | 文件（相对于 `static/`） |
| --- | --- |
| 可爱风室内和四个姿势 | `candy/room.png`、`candy/witch-1.png` 至 `witch-4.png` |
| 清新风、丑萌风室内和两个姿势 | `candy/themes/<主题>/room.png`、同目录的 `witch-1.png`、`witch-2.png` |
| 花园全景中的小屋 | `garden/themes/<主题>/depth/near-candy.png`，共用后备图在 `garden/depth/` |
| 推门前的近景 | `garden/themes/<主题>/near/candy_main.png` |

室内底图按容器裁切，中心区域留给人物。角色立绘按 `witch-N` 的数字顺序切换。添加姿势时使用透明背景、统一角色比例和五种印色，刷新页面即可读到新图。桌面与手机的构图在 `css/candy_house.css` 的 `.candy-stage` 和 `.candy-cast` 中调整。

花园的透明全景图包含建筑定位所需的留白。替换时保持画布尺寸、建筑中心与脚点，进花园检查点击位置和近景是否对应。

插画来源和生成说明见[樱桃小屋插画来源](../../../文档/素材来源/樱桃小屋.md)。
