# 花园视差层素材（待替换）

这五个 PNG 是**占位图**，用来占好尺寸与位置。美工按下面的规格重画后，
**用同名文件覆盖**即可，不需要改任何代码。

## 五层规格

| 文件名 | 是哪一层 | 视差系数 | 说明 |
|---|---|---|---|
| `layer-1-sky.png` | 天空（最远） | 0.06 | **不透明**。渐变天空＋太阳。几乎不动 |
| `layer-2-mountains.png` | 远山＋云 | 0.16 | 透明底。山脊在中下部，上方留空给天空 |
| `layer-3-trees.png` | 中景树林 | 0.32 | 透明底。树冠饱满、色彩可略深 |
| `layer-4-ground.png` | 草地＋小路 | 0.58 | 透明底。占画面下半部，小路在正中 |
| `layer-5-foreground.png` | 前景花草 | 0.95 | 透明底。**动得最多**，建议画得低对比/微虚化 |

## 三条硬要求

1. **画布尺寸必须是 2560×1440**，五层完全一致 —— 不一致就会错位。
2. **除天空层外，其余四层背景必须透明**（导出 PNG-24 + Alpha，不要白底）。
3. **小路要留在画面水平中央**。它是视觉引导线，偏了会让花园"歪"。

## 视差怎么产生的

鼠标移动 / 手指拖动 / 手机倾斜时，各层按上表的系数**朝不同方向平移**：
近层移动多、远层移动少，大脑就会读成纵深感。
所以**越近的层越不能画得太满**，否则移动时会露出边缘。

## 参考

同目录 `_reference-composite.png` 是五层叠加后的完整效果（也是当前页面的样子），
可以对着它确认各层的相对位置。

## 换完怎么验证

替换后直接刷新花园页面即可。若某层显示不出来，检查：
- 文件名是否完全一致（区分大小写）
- 是否真的是 PNG 且带 Alpha
- 尺寸是否 2560×1440
