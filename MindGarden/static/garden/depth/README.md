# 花园 3D 场景素材（待美工替换）

这一版用了**真透视 Z 轴**：每个景点是独立一层，放在不同的 Z 深度上，
相机前后移动时浏览器按透视自动缩放 —— 所以每张图都要**按满屏画布构图**，
画的就是"它在花园里该出现的位置和大小"。

## 各层 Z 深度与用途

| 文件名 | Z 深度 | 是什么 | 点击后去哪 |
|---|---|---|---|
| `layer-1-sky.png` | -2600 | 天空（复用旧素材） | — |
| `far-gallery.png` | -1700 | **艺术回廊**（远景） | 疗愈回廊 |
| `mid-sakura.png` | -1000 | **樱花树与树洞**（中景） | 树洞日记 |
| `layer-4-ground.png` | -420 | 草地与小路（复用旧素材） | — |
| `near-candy.png` | 0 | **糖果小屋**（近景·左） | AI 心理对话 |
| `near-mirror.png` | 0 | **镜池**（近景·右） | 摄像头小熊 |
| `layer-5-foreground.png` | 0 | 前景花草（复用旧素材，可留空） | — |

## 三条硬要求

1. **画布 2560×1440**，全部一致。
2. **背景透明**（PNG-24 + Alpha），不要白底 —— 层与层要能透出后面的景。
3. **位置按表来**：艺术回廊在画面中央、樱花树在正中、糖果小屋在左侧、
   镜池在右侧。位置偏了热区就对不上（热区坐标在 `garden3d.js` 里按同比例配置）。

## 换完怎么验证

刷新 `/garden` 即可。若某层看不到，检查文件名（区分大小写）、Alpha 通道、尺寸。
